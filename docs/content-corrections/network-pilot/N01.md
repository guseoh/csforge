## N-01 contract

The five existing frames are preserved with fixed left/right endpoints and aligned timeline rows. A half-length, bold arrow means a message is **in flight**, not yet received by the remote TCP endpoint; a complete arrow means it was received. This explicitly prevents visual claims that the server is already ESTABLISHED before receipt of the final ACK.

| Step | Client | Server | Sent messages | In flight |
|---|---|---|---|---|
| 0 | CLOSED | LISTEN | 0 | — |
| 1 | SYN-SENT | LISTEN | 1 | SYN |
| 2 | SYN-SENT | SYN-RECEIVED | 2 | SYN+ACK |
| 3 | ESTABLISHED | SYN-RECEIVED | 3 | final ACK |
| 4 | ESTABLISHED | ESTABLISHED | 3 | — |

Example: client ISN 100, server ISN 300, zero payload, final ACK seq=101 ack=301. SYN consumes one sequence number; pure ACK does not. Sequence arithmetic remains modulo 2³². Simultaneous open, retransmission, TCP Fast Open, TLS and HTTP success are out of scope.
