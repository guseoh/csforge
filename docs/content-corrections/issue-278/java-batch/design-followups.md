# 기존 공통 UI/도식의 후속 재검토

이번 Batch는 네 Topic의 기술 품질·승인된 도식에 한정했습니다. 아래 항목은 공통 UI의 별도 리뷰 대상으로 남깁니다.

1. **Reader 라이트 모드 제목 대비.** `frontend/src/styles.css`의 `.markdown-content h2, h3`가 고정 밝은 색 `#eef2ff`를 사용합니다.
   실제 앱 CSS를 읽는 라이트 QA fixture에서도 본문 제목 대비가 낮았습니다. 이 색은 이번 변경 전부터 존재합니다.
   Markdown 원본 문제가 아니므로 이번 Content Pack에서 Reader 전역 스타일을 변경하지 않았습니다.
2. **좁은 화면의 고정 canvas.** 현재 15px 글자와 내부 가로 이동을 유지합니다. 가로 스크롤/키보드 이동과 상태 문장은 확인했지만,
   긴 관계를 더 적은 이동으로 읽는 반응형 표현은 공통 설계 단계에서 재검토할 가치가 있습니다.
3. **기존 static-flow와 힙의 표시 밀도.** 이번 선형 변환 두 개에는 기존 순차 흐름을 사용했고,
   PriorityQueue V3는 승인된 KEEP을 유지했습니다. 동일한 사각형/화살표를 다른 기술 주제에 자동 확장하지 않습니다.
   기존 도식의 여백·범례·단계 기록 배치는 이후 디자인 리뷰에 포함합니다.
4. **과거 외부 SVG.** canonical 새 본문은 inline 토큰을 따르지만 이전에 저장된 본문/노트는 과거 SVG URL을 사용할 수 있습니다.
   호환을 위해 기존 27개 파일을 삭제하지 않았습니다. 다른 Java Topic의 SVG 교체와 최종 미사용 자산 정리는 후속 Pack의 판정을 따릅니다.
5. **독립 리뷰 상태.** 기존 J-object-model의 구현 기록을 승인 완료로 바꾸지 않았습니다.
   이 네 Pack도 단일 에이전트의 구현·자체 검증 결과이며, 외부 Reviewer 승인을 받은 것으로 표시하지 않습니다.

새 inline 도식 자체의 다크/라이트 토큰·텍스트 범위·조작 결과는 이번 Batch 검증을 통과했습니다.
