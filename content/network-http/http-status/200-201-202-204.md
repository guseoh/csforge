# 성공 응답: 200·201·202·204

2xx 상태 코드는 모두 성공 응답 계열에 속하지만, 요청이 어느 단계까지 진행됐는지와 응답 콘텐츠의 의미는 서로 다르다.

`200 OK`는 요청이 성공했다는 가장 일반적인 응답이다. 메서드에 따라 선택된 표현이나 처리 결과를 콘텐츠로 반환할 수 있다.

`201 Created`는 요청 처리 결과 하나 이상의 리소스가 생성됐음을 나타낸다. 새 리소스를 가리키는 URI는 `Location` 필드나 요청 대상의 의미를 통해 알 수 있다.

`202 Accepted`는 요청을 **처리 대상으로 받아들였지만 처리가 아직 완료되지 않았을 수 있음**을 뜻한다. HTTP 자체는 이후 비동기 작업의 성공을 보장하지 않는다. 장기 작업이라면 애플리케이션이 진행 상황이나 결과를 확인할 별도 상태 리소스를 제공할 수 있다.

`204 No Content`는 요청은 성공했지만 응답 콘텐츠를 보내지 않는 경우다. 클라이언트가 새 표현을 받을 필요가 없을 때 사용할 수 있다.

```text
200 → 성공, 일반적인 결과를 반환할 수 있음
201 → 성공 + 리소스 생성
202 → 처리를 수락했지만 아직 완료되지 않음
204 → 성공 + 응답 콘텐츠 없음
```

이 차이를 알면 모든 성공을 `200` 하나로 표현하지 않고, **현재 작업의 상태를 어떻게 해석해야 하는지** HTTP 응답으로 더 정확히 전달할 수 있다.
