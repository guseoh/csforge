# 409 and 412

409 Conflict는 request가 현재 resource state와 충돌해 처리할 수 없음을 나타내며, 412 Precondition Failed는 If-Match나 If-Unmodified-Since 같은 조건이 거짓인 상태다. 둘 다 concurrent update와 연결될 수 있지만 조건부 header failure와 domain conflict의 원인이 다르다.

client가 최신 representation을 읽고 merge하거나 version을 갱신하는 recovery path가 필요하다. 무조건 retry하면 같은 충돌을 반복할 수 있어 conflict detail과 현재 version을 안전하게 제공한다.

### Backend 연결

content reimport의 version mismatch는 412, 동일 stable key의 incompatible payload는 409처럼 계약을 나눌 수 있다. error response에 canonical data를 과도하게 노출하지 않는다.
