# 415 and 422

415 Unsupported Media Type는 server가 request content의 media type이나 content coding을 지원하지 않는 경우다. 422 Unprocessable Content는 syntax와 media type은 이해했지만 semantic validation이나 instruction을 처리할 수 없는 경우에 사용한다.

parser failure와 domain invariant failure를 구분하면 client가 body format을 고칠지 값과 상태를 고칠지 알 수 있다. status를 임의로 통일하면 observability와 retry policy가 흐려진다.
