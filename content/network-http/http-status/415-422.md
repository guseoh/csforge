# 표현 오류: 415·422

`415 Unsupported Media Type`은 서버가 요청 콘텐츠의 형식을 현재 메서드와 대상에서 지원하지 않아 처리를 거부하는 상태다. 원인은 `Content-Type`으로 선언한 미디어 유형, 콘텐츠 코딩 또는 실제 콘텐츠 형식과 관련될 수 있다.

예를 들어 JSON만 받는 엔드포인트에 `Content-Type: application/xml`을 보냈고 서버가 XML을 지원하지 않는다면 415가 적절할 수 있다. 문제는 콘텐츠가 표현하는 업무 값이 아니라 **서버가 해당 표현 형식을 처리할 수 없다는 것**이다.

`422 Unprocessable Content`는 콘텐츠 유형과 문법은 이해했지만 그 안에 담긴 지시를 처리할 수 없는 경우다. 예를 들어 구조상 올바른 JSON이라도 요청한 상태 전환이나 필드 관계를 현재 서버가 적용할 수 없다면 422를 고려할 수 있다.

```text
415 → 이 콘텐츠 표현 형식을 지원하지 않음
422 → 콘텐츠 유형과 문법은 이해했지만 지시를 처리할 수 없음
```

`JSON 파싱 실패`, `지원하지 않는 미디어 유형`, `파싱은 성공했지만 요청 의미를 처리할 수 없음`을 하나의 오류로 합치지 않는 편이 좋다. 422를 특정 검증 도구의 상태 코드로만 외우기보다 **표현은 이해했지만 콘텐츠에 담긴 지시를 처리할 수 없는 HTTP 상태**로 이해해야 한다.
