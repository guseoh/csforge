# 415 Unsupported Media Type와 422 Unprocessable Content

`415 Unsupported Media Type`는 server가 request content의 format을 현재 method와 target에서 지원하지 않아 처리를 거부하는 상태다. 원인은 `Content-Type`으로 선언한 media type, content coding 또는 실제 content 형식과 관련될 수 있다.

예를 들어 JSON만 받는 endpoint에 `Content-Type: application/xml`을 보냈고 XML을 지원하지 않는다면 415가 의미에 잘 맞는다. 이 경우 문제는 content가 표현하려는 업무 값이 아니라 **server가 해당 representation 형식을 처리하지 못한다는 것**이다.

`422 Unprocessable Content`는 content type을 이해하고 content syntax도 올바르지만, 포함된 instructions를 처리할 수 없는 경우다. 예를 들어 구조적으로 올바른 JSON이더라도 request가 요구하는 상태 전환이나 field 관계를 server가 적용할 수 없다면 422가 후보가 될 수 있다.

```text
415 → 이 content representation을 지원하지 않음
422 → content type과 syntax는 이해했지만 지시를 처리할 수 없음
```

따라서 `JSON parse 자체가 실패함`, `지원하지 않는 media type`, `parse는 됐지만 요청 의미를 처리할 수 없음`을 하나의 오류로 합치지 않는 편이 좋다. 422를 단순히 특정 validation framework의 status로 외우기보다 **representation은 이해했지만 content에 담긴 instruction을 처리할 수 없는 HTTP 상태**로 이해해야 한다.
