# 표현 오류: 415·422

415 Unsupported Media Type은 현재 대상과 메서드가 요청 콘텐츠의 형식을 지원하지 않아 처리를 거부하는 응답입니다. 미디어 유형뿐 아니라 콘텐츠 코딩이나 실제 형식도 원인이 될 수 있습니다.

예를 들어 JSON만 지원하는 엔드포인트에 application/xml 콘텐츠를 보내면 415가 적절할 수 있습니다.

422 Unprocessable Content는 콘텐츠 유형과 문법을 이해했지만 콘텐츠의 지시를 처리할 수 없는 경우입니다. 유효한 JSON 안에서 서로 양립할 수 없는 필드 값이나 허용되지 않는 변경 지시가 예입니다.

| 문제 | 가능한 상태 |
| --- | --- |
| 지원하지 않는 콘텐츠 형식 | 415 |
| 깨진 JSON 문법 | 일반적으로 400 |
| 문법은 맞지만 의미상 처리할 수 없는 지시 | 422 |

모든 Bean Validation 오류에 422를 강제하는 것은 아닙니다. API의 오류 계약과 해당 실패의 의미에 따라 상태를 일관되게 선택하고 상세 오류를 제공해야 합니다.
