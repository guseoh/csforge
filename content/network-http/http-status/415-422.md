# 415 and 422

`415 Unsupported Media Type`는 server가 request content의 media type이나 content coding을 지원하지 않아 representation을 처리할 수 없는 경우다. `422 Unprocessable Content`는 syntax와 media type은 이해했고 parsing도 가능하지만, 포함된 instruction이나 field 값이 현재 resource/domain 규칙상 처리될 수 없는 경우에 사용한다. malformed syntax 자체는 400 같은 다른 오류 경계가 될 수 있다.

parser가 body format을 이해하지 못한 것과 semantic validation·domain invariant가 실패한 것을 구분하면 client는 Content-Type/encoding을 고칠지 값과 상태를 고칠지 알 수 있다. status를 임의로 통일하면 observability와 retry policy가 흐려지고, 422를 받았다고 body bytes가 canonical state에 반영됐다고 볼 수 없다.

CSForge import Preview에서 JSON/YAML parser와 media type 오류, schema·published concept required field·domain invariant 오류를 분리한다. API response는 field path와 안전한 validation reason을 제공하되 원본 content나 내부 stack trace를 과도하게 노출하지 않는다.
