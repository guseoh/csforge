# 500, 502, 503·504

`500 Internal Server Error`는 origin이 요청을 처리하는 중 예상하지 못한 내부 오류를 만난 일반적인 server 실패다. `502 Bad Gateway`는 gateway/proxy가 upstream에서 유효하지 않은 응답을 받았고, `503 Service Unavailable`은 현재 일시적으로 요청을 처리할 준비가 되지 않았으며, `504 Gateway Timeout`은 gateway가 정해진 시간 안에 upstream 응답을 받지 못했음을 표현한다.

이 code들은 retry 가능성을 자동으로 결정하지 않는다. 502/504 직전에 upstream이 요청과 side effect를 이미 수행했을 수 있고, 503이 overload·maintenance·dependency 실패 중 무엇인지도 policy가 정한다. `Retry-After`, idempotency, upstream timing·connection state와 전체 deadline을 함께 보고 retry 여부를 제한한다.

reverse proxy와 Spring app이 status를 서로 덮어쓰지 않도록 origin exception, upstream invalid 응답과 gateway timeout을 trace로 연결한다. 503에는 overload·maintenance·Retry-After 정책을 명시하고, 504에는 upstream connect/read deadline과 pool wait를 조사하며 외부 응답에는 내부 stack trace를 노출하지 않는다.
### 실패 ownership by hop
    client → proxy → origin
             ├─ 502/504 upstream 실패
             └─ origin 500/503 app/dependency 실패
status와 trace를 함께 봐야 실패 hop을 구분할 수 있다.
