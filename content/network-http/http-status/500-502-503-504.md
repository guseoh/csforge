# 서버 오류: 500·502·503·504

5xx는 서버 측 오류 또는 처리 불가를 나타냅니다. 어느 HTTP 참가자가 오류를 발생시켰고 어떤 조건에 실패했는지 구분해야 합니다.

```csforge-viz
{
  "version": 1,
  "type": "network-area",
  "title": "서버 오류: 500·502·503·504",
  "description": "메시지 전달의 계층과 프로토콜 의미를 고정 예제로 비교합니다.",
  "example": "500-502-503-504"
}
```

| 상태 | 의미 |
| --- | --- |
| 500 | 예상하지 못한 서버 내부 조건으로 처리 실패 |
| 502 | 게이트웨이가 상위 서버에서 유효하지 않은 응답을 받음 |
| 503 | 과부하·점검 등으로 일시적으로 처리 불가 |
| 504 | 게이트웨이가 필요한 상위 응답을 제시간에 받지 못함 |

### 재시도와 관찰

503은 Retry-After로 재시도 시점을 안내할 수 있습니다. 504는 상위 서버가 작업을 실행하지 않았다는 증거가 아닙니다. 예를 들어 주문 저장은 완료됐지만 게이트웨이의 대기 시간이 먼저 끝날 수 있습니다.

상태 코드만으로 재시도를 결정하지 않고 요청의 멱등성, 시간 예산 및 실제 처리 여부를 확인합니다. 프록시 접근 로그와 upstream 상태, 백엔드 로그를 요청 ID로 연결하면 오류를 생성한 홉을 좁힐 수 있습니다.
