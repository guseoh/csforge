# 500, 502, 503 and 504

500은 origin server가 예상하지 못한 내부 오류를, 502는 gateway가 upstream에서 유효하지 않은 응답을 받은 상태를, 503은 일시적으로 service를 처리할 수 없는 상태를, 504는 gateway가 upstream 응답을 제때 받지 못한 상태를 표현한다.

이 code들은 retry 가능성을 자동으로 결정하지 않는다. side effect가 이미 수행됐을 가능성, Retry-After, overload와 dependency health를 함께 본다.

### Backend 연결

reverse proxy와 Spring app이 status를 서로 덮어쓰지 않도록 origin failure와 gateway failure를 trace로 연결한다. 503에는 overload·maintenance·retry-after 정책을 명시하고 504에는 upstream deadline을 조사한다.
