# 서버 오류: 500·502·503·504

5xx 상태 코드는 서버 오류 계열이지만 `어느 HTTP 참가자가 어떤 이유로 실패했는가`는 상태 코드마다 다르다.

`500 Internal Server Error`는 서버가 요청을 처리하는 중 예상하지 못한 조건을 만나 요청을 완료할 수 없을 때 쓰는 일반적인 내부 오류다.

`502 Bad Gateway`는 게이트웨이나 프록시가 상위 서버와 통신하다 **유효하지 않은 응답을 받은 경우**다. 이때 502를 클라이언트에게 반환하는 주체는 중간 게이트웨이이며, 클라이언트가 원본 서버의 500을 직접 받은 상황과 다르다.

`503 Service Unavailable`은 서버가 일시적인 과부하나 점검 등으로 현재 요청을 처리할 준비가 되지 않은 상태다. 가능하면 `Retry-After`를 사용해 예상 복구 시점을 알려 줄 수 있다.

`504 Gateway Timeout`은 게이트웨이나 프록시가 요청을 처리하는 데 필요한 상위 서버의 응답을 정해진 시간 안에 받지 못한 경우다.

```text
500 → 현재 서버의 내부 처리 실패
502 → 게이트웨이가 상위 서버에서 유효하지 않은 응답을 받음
503 → 서버가 일시적으로 요청을 처리할 수 없음
504 → 게이트웨이가 상위 서버 응답을 제때 받지 못함
```

이 상태 코드들이 재시도를 자동으로 보장하지는 않는다. 특히 게이트웨이 시간 초과가 발생했어도 상위 서버가 요청을 일부 또는 전부 처리했을 수 있다. 따라서 상태 코드의 의미와 요청 메서드의 재시도·멱등성 의미를 함께 살펴야 한다.

핵심은 5xx를 하나의 `서버 오류`로 뭉개지 않고 **오류를 반환한 HTTP 홉과 실패 종류를 구분하는 것**이다.
