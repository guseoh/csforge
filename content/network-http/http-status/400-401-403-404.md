# 요청 오류: 400·401·403·404

4xx는 요청과 관련된 실패를 나타내지만 원인과 해결 방법은 서로 다릅니다.

| 상태 | 의미 | 예 |
| --- | --- | --- |
| 400 | 잘못된 요청으로 처리 불가 | 잘못된 JSON 문법 |
| 401 | 유효한 인증 자격이 없음 | 만료된 인증 토큰 |
| 403 | 요청을 이해했으나 수행 거부 | 권한 정책 위반 |
| 404 | 현재 표현을 찾지 못했거나 존재를 공개하지 않음 | 없는 주문 ID |

401 응답에는 대상 리소스에 적용할 인증 challenge를 WWW-Authenticate로 제공해야 합니다. 403은 요청을 이해했지만 거부하는 상태로 새로운 자격을 제공해도 반드시 해결되는 것은 아닙니다.

### 접근 권한과 자원 존재 여부

다른 사용자의 문서를 조회하는 요청에 403 대신 404를 반환하여 존재 여부를 숨길 수 있습니다. 외부 응답은 일관된 보안 정책에 따르고 내부 감사 기록은 실제 거부 원인을 구분해야 합니다.

401을 무조건 로그인하지 않은 상태, 403을 무조건 로그인한 상태로 대응시키지 않습니다. 인증 자격의 유효성과 권한 정책, 공개 여부라는 HTTP 의미를 기준으로 판단합니다.
