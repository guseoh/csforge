# 400·401·403·404의 차이

4xx는 모두 client error class에 속하지만 요청을 수행할 수 없는 이유는 서로 다르다.

`400 Bad Request`는 malformed syntax, invalid message framing처럼 server가 client 쪽 오류라고 판단한 이유 때문에 request를 처리할 수 없거나 처리하지 않겠다는 일반적인 상태다.

`401 Unauthorized`는 이름과 달리 주로 **authentication이 필요하거나 제공된 authentication credential이 유효하지 않은 상태**를 나타낸다. 401을 보내는 server는 해당 target에 적용할 수 있는 authentication challenge를 `WWW-Authenticate` field로 제공해야 한다.

`403 Forbidden`은 server가 request를 이해했지만 수행을 거부하는 상태다. 유효한 credential이 있더라도 현재 principal에게 필요한 권한이 없거나 policy상 요청을 허용하지 않는 경우가 여기에 해당할 수 있다. credential을 새로 제공한다고 반드시 해결되는 상태는 아니다.

`404 Not Found`는 target resource의 current representation을 찾지 못했거나, server가 그 resource의 존재 여부를 공개하지 않으려는 경우에도 사용할 수 있다.

```text
400 → request 자체를 처리하기 어려운 client-side 문제
401 → authentication challenge가 필요함
403 → 이해했지만 수행을 거부함
404 → target resource를 찾지 못했거나 존재를 숨김
```

따라서 401을 단순히 `로그인 안 함`, 403을 `로그인했지만 권한 없음`이라고만 외우기보다 **authentication을 다시 시도해야 하는가, server가 현재 request를 허용하지 않는가, target 자체를 찾을 수 없는가**라는 protocol 의미로 구분하는 편이 정확하다.
