# 304 Not Modified

304는 conditional GET/HEAD의 validator가 현재 representation과 일치해 response content를 다시 보내지 않아도 되는 상태다. client는 저장해 둔 representation과 필요한 metadata를 결합해 결과를 만든다.

304는 일반 성공 body가 없고 cache metadata 갱신 목적이 있으므로 API client가 JSON body를 항상 기대하면 안 된다. representation이 없거나 cache entry가 사라진 client는 조건부 요청 대신 일반 요청을 수행한다.

### Backend 연결

Spring controller와 proxy가 304를 body 변환·gzip 처리로 망가뜨리지 않는지 검증한다. ETag match 뒤에도 권한과 tenant scope를 먼저 확인한다.
