# 304 Not Modified

`304 Not Modified`는 conditional GET 또는 HEAD에서 client가 가진 stored representation이 여전히 재사용 가능하다고 판단될 때 사용하는 response다. Server는 representation content를 다시 보내지 않고, client나 cache가 기존 body를 계속 사용하게 한다.

```text
stored body + validator
        ↓ conditional GET
server validator match
        ↓
304 Not Modified
        ↓
reuse stored body
```

304는 `아무 변화가 없다`는 일반 application status가 아니다. ETag의 `If-None-Match`나 날짜 기반 `If-Modified-Since` 같은 HTTP precondition 평가 결과로 사용하는 protocol response다.

304 response에는 message content가 없지만 cache state를 갱신하는 데 필요한 `ETag`, `Cache-Control`, `Expires`, `Vary` 같은 metadata가 포함될 수 있다. Recipient는 stored response의 body를 유지하면서 새 metadata를 반영해 cache entry를 갱신한다.

따라서 stored body 자체가 없는 client는 304만으로 representation을 복원할 수 없다. **304는 이미 저장된 representation을 재사용하기 위한 validation 결과이며, 새로운 representation body를 전달하는 response가 아니다.**
